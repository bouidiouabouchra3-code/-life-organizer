# Life Organizer — P04

## الجديد في P04 — المصاريف الفعلية
- كل وظائف P02 وP03 ما زالت موجودة.
- قسم المصاريف أصبح فعليًا بالكامل:
  - إضافة دخل أو مصروف.
  - المبلغ + الوصف + التاريخ + التصنيف + ملاحظة اختيارية.
  - تعديل وحذف أي حركة مالية.
  - اختيار الشهر وعرض بياناته فقط.
  - فلاتر: الكل / المصروف / الدخل.
  - إجمالي الدخل والمصروفات والرصيد.
  - توزيع المصاريف حسب الفئات مع نسب وأشرطة بصرية.
  - قائمة بالحركات المالية.
  - اختيار العملة: ج.م / ر.س / د.إ / $ / €.
  - حفظ كل البيانات محليًا على الجهاز.
- Dashboard تعرض مصروفات ورصيد الشهر الحالي.
- المصاريف أصبحت موجودة في شريط التنقل السفلي.
- بيانات P02/P03 محفوظة لأن مفاتيح التخزين القديمة لم تتغير.
- Service Worker محدث إلى P04.

## القادم
- P05: متتبع العادات.
- P06: مخطط الدراسة.
- P07+: البحث الشامل، النسخ الاحتياطي، تحسينات نهائية.

لا توجد أرقام أو معاملات جاهزة داخل التطبيق؛ كل الحركات المالية تدخلينها أنتِ.
