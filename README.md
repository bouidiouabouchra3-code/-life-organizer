## بعد الرفع على iPhone
إذا ظهر الاسم أو الأيقونة القديمة:
1. افتحي الموقع في Safari واعملي Refresh.
2. احذفي أيقونة التطبيق القديمة من Home Screen فقط.
3. من Safari اختاري Share > Add to Home Screen مرة ثانية.
4. ستظهر Bloomie بالاسم والأيقونة الجديدة.
