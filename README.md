# Bloomie — P20 Selective Sharing

## الجديد في P20 — مشاركة خطتي 📤

### 📤 مركز مشاركة انتقائي
يمكن الآن تجهيز نص قابل للمشاركة بدون إرسال كل بيانات Bloomie.

الأقسام المتاحة:
- ✅ المهام.
- 🎓 الدراسة.
- 🌿 العادات.
- 🎯 الأهداف.

### ⚡ Presets جاهزة
- **خطة اليوم**: مهام + دراسة + عادات لليوم.
- **المهام**: المهام فقط لمدة 7 أيام.
- **الدراسة**: جدول الدراسة فقط لمدة 7 أيام.
- **مخصص**: اختاري الأقسام بنفسك.

### 📅 فترة المشاركة
يمكن اختيار:
- اليوم.
- 7 أيام.
- هذا الشهر.

### 🎛️ خيارات
- إخفاء أو إظهار العناصر المكتملة.
- إظهار الأوقات أو إخفاؤها.
- إظهار التصنيفات أو إخفاؤها.

### 👀 معاينة قبل الإرسال
Bloomie يبني النص أولًا ويعرض Preview كامل.
لا يتم إرسال شيء حتى تضغطي زر المشاركة.

### 📱 مشاركة iPhone
زر **مشاركة** يستخدم Share Sheet الخاص بالجهاز إذا كان متاحًا، لذلك يمكن اختيار WhatsApp أو Messages أو أي تطبيق آخر من قائمة المشاركة.

### 📋 نسخ و TXT
يوجد أيضًا:
- نسخ النص.
- تنزيل ملف TXT.

### 🔒 الخصوصية
P20 لا يضيف تلقائيًا إلى المشاركة:
- الملاحظات.
- الأفكار.
- المصاريف أو الدخل.
- المزاج.
- PIN.
- ملفات Backup.

فقط الأقسام التي تختاريها من شاشة المشاركة تدخل في النص.

### البيانات
P20 لا يحتاج مفتاح تخزين جديد ولا يرسل البيانات إلى سيرفر.
كل النص يتم إنشاؤه محليًا داخل Bloomie.

Backup وImport من الإصدارات السابقة يظلان متوافقين.
